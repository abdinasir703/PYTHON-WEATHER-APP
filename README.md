# PYTHON WEATHER APP 

## ABOUT THE PROJECT

The Python Weather App is a simple command-line application that fetches real-time weather information for any city using the OpenWeatherMap API.

## FEATURES

- Search for weather information by city name.
- Display temperature in Celsius.
- Show the feels-like temperature.
- Display current weather conditions.
- Show humidity and wind speed.
- Handle invalid city names and network errors.
- Search for multiple cities without restarting the program.

## HOW TO RUN

1. Clone or download this repository.
2. Install the required library:

   ```bash
   pip install requests
   ```

3. Open the project in PyCharm.
4. Configure your OpenWeatherMap API key.
5. Run the program:

   ```bash
   python weather_app.py
   ```

## SECURITY

- Keep your OpenWeatherMap API key private.
- Never upload your actual API key to a public GitHub repository.
- Use environment variables to store sensitive API credentials.
- Add files containing secrets to `.gitignore`.
- If an API key is accidentally exposed, revoke it and generate a new one.
